# Exercícios em Java

Este repositório contém um conjunto de atividades e exercícios práticos com foco na aprendizagem da Linguagem de Programação **Java** e pilares da **POO**

## Conceitos Práticos 

Os exercícios abordam desde fundamentos básicos até estruturas elaboradas de POO, alguns exemplos:

* **Classes e Objetos:** Criação de moldes (`Classes.java`) e instanciação de objetos reais (`Objetos.java`).
* **Atributos e Métodos:** Definição de comportamentos e características (`Métodos.java`, `Método abstrato.java`).
* **Construtores e Destrutores:** Inicialização e gerenciamento do ciclo de vida dos objetos (`Construtores.java`, `Destrutores.java`).
* **Encapsulamento e Escopo:** Proteção de dados e visibilidade de variáveis (`Encapsulamento.java`, `Escopo.java`).
* **Herança e Polimorfismo:** Reutilização de código e especialização de classes (`Heranca.java`).
* **Interfaces:** Criação de contratos de comportamento para as classes (`Interfaces.java`).
* **Estudo de Caso (Sistema Bancário):** Aplicação prática dos conceitos simulando contas bancárias (`Conta.java`, `ContaCorrente.java`, `ContaPoupanca.java`).
